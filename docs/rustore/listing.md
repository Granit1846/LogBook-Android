# Карточка приложения для RuStore

**Название:** LogBook — лётная книжка

**Краткое описание:** Электронная лётная книжка для экипажей вертолётов и учёта ресурсов.

**Полное описание:**

LogBook помогает экипажам вертолётов вести записи о полётах и техническом состоянии воздушного судна. В приложении доступны лётная книжка, формуляры ВР-80, ТА-14 и ВК-2500, учёт ресурсов масел и агрегатов, а также журнал технического обслуживания.

Данные хранятся на устройстве. Можно создать резервную копию, обмениваться данными с приложением для Windows по Wi-Fi и синхронизировать записи через учётную запись. Для входа доступны электронная почта и боты Telegram и MAX. Также доступно мини-приложение для Telegram и MAX.

Приложение показывает предупреждения о приближении сроков обслуживания и исчерпании ресурсов. Обновления версии RuStore открываются в магазине.

**Предлагаемая категория:** Работа / Инструменты.

## Разрешения

- `INTERNET` — вход в учётную запись и облачная синхронизация.
- `ACCESS_LOCAL_NETWORK` — обмен данными с приложением для Windows по Wi-Fi.
- `CAMERA` — сканирование QR-кода для сопряжения с ПК.
- `POST_NOTIFICATIONS` — уведомления о предупреждениях по ресурсам.
- `RECEIVE_BOOT_COMPLETED` — восстановление расписания ежедневных предупреждений после перезагрузки.

**Что нового:** Первая версия LogBook в RuStore: учёт полётов и ресурсов, формуляры, журнал обслуживания, резервные копии и синхронизация.
